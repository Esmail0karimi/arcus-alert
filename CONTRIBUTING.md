# Contributing

Thanks for considering a contribution to Arcus Alert.

## Before opening a pull request

- Search existing issues and pull requests to avoid duplicate work.
- Keep changes focused and avoid unrelated refactors.
- Describe the user-visible behavior and the reason for the change.
- Include screenshots for UI changes.
- Test the Windows build when changing the desktop application.

## Reporting bugs

Include:
- Arcus Alert version and Windows version.
- Steps to reproduce.
- Expected and actual behavior.
- Screenshots or logs, with all credentials and secrets removed.

## Security

Do not report vulnerabilities in public issues. Follow [SECURITY.md](SECURITY.md).
